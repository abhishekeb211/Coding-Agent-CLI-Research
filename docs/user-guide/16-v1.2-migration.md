# Migrating to v1.2

## Overview

Version 1.2 introduces major new features while maintaining backward compatibility with v1.0. This guide helps you upgrade smoothly and take advantage of new capabilities.

## What's New in v1.2

### Major Features
- **Web Dashboard**: Browser-based UI for viewing findings and analytics
- **REST API**: Full programmatic access to all functionality
- **Real LLM Providers**: OpenAI, Anthropic, and Ollama support
- **Additional Scanners**: gosec (Go) and eslint-plugin-security (JS/TS)
- **CI/CD Integration**: GitHub Actions and GitLab CI templates
- **Advanced Analytics**: Trends, MTTR, security scores, hotspots
- **Custom Templates**: Create custom report formats
- **Enhanced Policies**: Glob and regex pattern matching
- **Webhooks**: Real-time notifications to Slack, Discord, Teams
- **Performance**: Incremental scanning and optimized queries

## Upgrade Process

### 1. Backup Your Data

Before upgrading, backup your database:

```bash
# Backup database
cp ~/.coding-agent-cli/findings.db ~/.coding-agent-cli/findings.db.backup

# Backup configuration
cp config.yaml config.yaml.backup
```

### 2. Install v1.2

**Download binary**:
```bash
curl -sSL https://install.coding-agent-cli.dev | sh
```

**Or build from source**:
```bash
git clone https://github.com/coding-agent/cli.git
cd cli
git checkout v1.2.0
go build -o coding-agent-cli
```

### 3. Run Database Migration

The database schema is automatically migrated on first run:

```bash
coding-agent-cli migrate
```

Or let it migrate automatically:
```bash
coding-agent-cli scan ./code
```

The migration:
- Creates new tables for analytics, webhooks, and API tokens
- Adds indexes for performance
- Preserves all existing data
- Can be rolled back if needed

### 4. Update Configuration

v1.2 adds new configuration options. Update your `config.yaml`:

```yaml
# New in v1.2: Web server configuration
web:
  enabled: true
  port: 8080
  host: localhost

# Existing: Scanners (now with more options)
scanners:
  enabled:
    - bandit
    - semgrep
    - gosec      # New scanner
    - eslint     # New scanner
  parallel: true
  timeout: 600

# Updated: LLM configuration with real providers
llm:
  enabled: true
  provider: openai  # New: openai, anthropic, ollama, mock
  model: gpt-4-turbo
  api_key: ${OPENAI_API_KEY}
  cache_enabled: true
  cost_limit_per_scan: 5.00  # New: cost control

# Existing: Policies (now with pattern matching)
policies:
  enabled: true
  paths:
    - ./policies/security.yaml

# New in v1.2: Webhooks
webhooks:
  - id: slack-alerts
    url: https://hooks.slack.com/services/YOUR/WEBHOOK
    events:
      - scan_complete
      - critical_finding
    enabled: true

# Existing: Privacy controls
privacy:
  redact_secrets: true
```

### 5. Install New Scanners (Optional)

If you want to use the new scanners:

**gosec (Go)**:
```bash
go install github.com/securego/gosec/v2/cmd/gosec@latest
```

**eslint-plugin-security (JavaScript/TypeScript)**:
```bash
npm install -g eslint eslint-plugin-security
```

### 6. Verify Installation

```bash
# Check version
coding-agent-cli --version
# Should show: v1.2.0

# Run a test scan
coding-agent-cli scan ./test-repo

# Start web dashboard
coding-agent-cli serve
# Visit http://localhost:8080
```

## Breaking Changes

### None!

v1.2 is fully backward compatible with v1.0:
- All v1.0 commands work unchanged
- Configuration files are compatible
- Database schema is migrated automatically
- CLI flags remain the same

## Configuration Changes

### LLM Provider Configuration

**v1.0 (Mock only)**:
```yaml
llm:
  enabled: true
  model: mock
```

**v1.2 (Real providers)**:
```yaml
llm:
  enabled: true
  provider: openai  # or anthropic, ollama
  model: gpt-4-turbo
  api_key: ${OPENAI_API_KEY}
  cost_limit_per_scan: 5.00
```

### Scanner Configuration

**v1.0**:
```yaml
scanners:
  - bandit
  - semgrep
```

**v1.2**:
```yaml
scanners:
  enabled:
    - bandit
    - semgrep
    - gosec
    - eslint
  parallel: true
  timeout: 600
```

### Policy Pattern Matching

**v1.0 (Basic matching)**:
```yaml
policies:
  - id: block-sql
    cwe:
      - CWE-89
    action: deny
```

**v1.2 (Pattern matching)**:
```yaml
policies:
  - id: block-sql
    cwe:
      - CWE-89
    patterns:
      include:
        - "**/*.py"
        - "src/**/*.js"
      exclude:
        - "**/test_*.py"
        - "**/*_test.js"
    action: deny
```

## New Features Guide

### Using the Web Dashboard

1. Start the server:
```bash
coding-agent-cli serve
```

2. Open browser to `http://localhost:8080`

3. Explore:
   - Home: Scan summary and statistics
   - Findings: Browse and filter findings
   - Analytics: View trends and metrics
   - Scans: Review scan history

See [Web Dashboard Guide](10-web-dashboard.md) for details.

### Using the REST API

1. Start the server:
```bash
coding-agent-cli serve
```

2. Make API calls:
```bash
# List findings
curl http://localhost:8080/api/v1/findings

# Trigger scan
curl -X POST http://localhost:8080/api/v1/scans \
  -H "Content-Type: application/json" \
  -d '{"path": "./code", "scanners": ["bandit"]}'
```

See [REST API Guide](11-rest-api.md) for details.

### Using Real LLM Providers

1. Set API key:
```bash
export OPENAI_API_KEY="sk-..."
```

2. Configure provider:
```yaml
llm:
  enabled: true
  provider: openai
  model: gpt-4-turbo
```

3. Run scan:
```bash
coding-agent-cli scan ./code --llm
```

See [LLM Integration Guide](08-llm-integration.md) for details.

### Setting Up CI/CD

**GitHub Actions**:

Create `.github/workflows/security-scan.yml`:
```yaml
name: Security Scan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: coding-agent/scan-action@v1
        with:
          path: ./src
          scanners: bandit,semgrep,gosec
```

**GitLab CI**:

Create `.gitlab-ci.yml`:
```yaml
include:
  - remote: 'https://raw.githubusercontent.com/coding-agent/cli/main/.gitlab-ci-template.yml'

security_scan:
  extends: .security_scan_template
```

See [CI/CD Integration Guide](13-cicd-integration.md) for details.

### Configuring Webhooks

1. Add to `config.yaml`:
```yaml
webhooks:
  - id: slack-alerts
    url: https://hooks.slack.com/services/YOUR/WEBHOOK
    events:
      - scan_complete
      - critical_finding
    enabled: true
```

2. Test webhook:
```bash
coding-agent-cli webhook test slack-alerts
```

See [Webhooks Guide](14-webhooks.md) for details.

## Performance Improvements

### Incremental Scanning

Scan only changed files:

```bash
# Automatic git-based detection
coding-agent-cli scan ./code --incremental

# Or specify changed files
git diff --name-only HEAD~1 > changed.txt
coding-agent-cli scan --files-from changed.txt
```

### Database Optimization

v1.2 includes:
- New indexes for faster queries
- Connection pooling
- Query optimization
- Streaming for large result sets

No configuration needed - automatic!

### Parallel Scanner Execution

Scanners now run in parallel by default:

```yaml
scanners:
  parallel: true  # Default in v1.2
```

## Troubleshooting

### Migration Issues

**Migration fails**:
```bash
# Rollback migration
coding-agent-cli migrate rollback

# Restore backup
cp ~/.coding-agent-cli/findings.db.backup ~/.coding-agent-cli/findings.db

# Try again
coding-agent-cli migrate
```

**Database locked**:
```bash
# Stop all running instances
pkill coding-agent-cli

# Try migration again
coding-agent-cli migrate
```

### Web Dashboard Issues

**Port already in use**:
```bash
# Use different port
coding-agent-cli serve --port 8081
```

**Dashboard not loading**:
- Check firewall settings
- Try `http://127.0.0.1:8080` instead of `localhost`
- Check server logs: `coding-agent-cli logs`

### LLM Provider Issues

**API key not working**:
```bash
# Verify key is set
echo $OPENAI_API_KEY

# Test with mock provider first
coding-agent-cli scan ./code --llm-provider mock
```

**Cost concerns**:
```yaml
llm:
  cost_limit_per_scan: 1.00  # Set lower limit
  estimate_cost: true         # Show estimate before scan
```

## Rollback to v1.0

If you need to rollback:

1. **Stop v1.2**:
```bash
pkill coding-agent-cli
```

2. **Restore backup**:
```bash
cp ~/.coding-agent-cli/findings.db.backup ~/.coding-agent-cli/findings.db
cp config.yaml.backup config.yaml
```

3. **Install v1.0**:
```bash
# Download v1.0 binary
curl -L https://github.com/coding-agent/cli/releases/download/v1.0.0/coding-agent-cli-linux-amd64.tar.gz | tar xz
```

4. **Verify**:
```bash
./coding-agent-cli --version
# Should show: v1.0.0
```
